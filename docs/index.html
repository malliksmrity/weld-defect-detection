Quality inspection · welding · computer vision

Upload a photo of a weld and a small model marks what it thinks are defects

The model was trained to find six things: bad welding, cracks, good welding, porosity (gas bubbles), reinforcement (excess weld metal) and spatter. It runs in your browser. The photo is not uploaded anywhere.

This is a demonstration of a student model. It is not a certified inspection tool, and its accuracy has not been measured on a proper test set (see Limits).

    How it works

    1. A YOLOv8 object-detection network was trained on labelled weld photos to draw boxes around six kinds of regions.
    2. The trained network was exported to the ONNX format (12 MB), which a browser can run with WebAssembly.
    3. Your photo is resized to 416 by 416 pixels, the network proposes boxes, and overlapping boxes are merged.

    Limits

    • The earlier README quoted mAP50 0.67, 15 ms per image and 6,335 training images. The training logs and dataset are not in this repository, so those figures can not be reproduced here and are not repeated on this page.
    • Only two photos were tried during this cleanup: a good weld was labelled “Good Welding” (confidence 0.86), a badly welded rusty corner got several “Bad Welding” boxes with confidence up to 0.58. Two photos prove nothing about accuracy.
    • The old Streamlit app only reported detections above 0.75 confidence. For the bad-weld photo above that would have shown nothing.
    • The class list has six entries. The earlier README named four types (porosity, cracks, undercut, spatter). The model has no “undercut” class.
    • Photos that look unlike the training data (lighting, metal, camera angle) will work worse.
